# Prédiction de salaires

> Pipeline de Machine Learning complet, de la donnée brute à une API prête à déployer, avec suivi des performances du modèle.

**ML & IA** · Terminé · Machine Learning · de bout en bout

**R² ≈ 0,98** sur 250 000 lignes

▶ **[Voir le projet dans le portfolio](https://dorline0121.github.io/#prediction-salaires)**

## Le projet

Un projet pensé comme en entreprise : le modèle ne s'arrête pas au notebook, il est servi par une API et surveillé une fois en place.

## Ce que fait le projet

- Préparation d'un jeu de données de 250 000 lignes
- Modèle XGBoost, hyperparamètres optimisés avec Optuna
- Coefficient de détermination R² ≈ 0,98
- API de prédiction Flask, conteneurisée avec un Dockerfile
- Tableau de bord de monitoring du modèle

## Technologies

`Python` · `XGBoost` · `Optuna` · `Flask` · `Docker`
